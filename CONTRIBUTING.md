# Comment aider ?

Merci de vouloir contribuer ! 

## Les étapes

1. Clone le repo
2. Crée une branche : `git checkout -b feature/ta-feature`
3. Fais tes changements
4. Commit : `git commit -m "Add: ma nouvelle feature"`
5. Push : `git push origin feature/ta-feature`
6. Ouvre une Pull Request

## Comment signaler un bug ?

Va sur [Issues](https://github.com/YojoxSn/calculatrice-cp/issues) et dis :
- Qu'est-ce qui ne marche pas ?
- Comment le reproduire ?
- Quel OS tu utilises ?

C'est tout !
